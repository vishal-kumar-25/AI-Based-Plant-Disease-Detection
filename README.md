# AI-Based-Plant-Disease-Detection
This a Deep Learning model using CNN for detecting plant disease 

https://ai-plant-disease-detection-rbrsnavzskhscufjd6pqw3.streamlit.app/

*Collaborated in a team to develop an AI model using a Convolutional
 Neural Network(CNN) implemented with Tensor Flow for detecting
 plant diseases from leaf images.

 *Utilized a dataset of healthy and diseased leaf images,achieving 85.85
 percent validation accuracy in disease classification.

 *Technologies Used: Python,TensorFlow,Keras,GoogleColab,Kaggle
 Dataset, andStreamlit for developmentanddeployment.
